# Changelog

## v1.0.0 — Release
- Объединены полный исходный проект v0.5.4 и переданный пакет Remaster Test 10.
- Добавлен список из 50 доступных стилей и проверка их доступности.
- Генератор анализирует геометрию открытого уровня и строит расстановку относительно существующего layout; ручное выделение области не требуется.
- Добавлено ограничение до 520 декоративных объектов на один проход.
- Проверка расстояний оптимизирована сравнением квадратов расстояний.
- Добавлены тесты повторяемости, длинных уровней и ограниченного размера результата.
- Создаваемые объекты остаются в стандартной истории Undo редактора.
- Версия `mod.json` и CMake обновлена до `1.0.0`.

## v0.5.4 — исходная база
- Адаптивная панель редактора и улучшенное размещение декора по внешним зонам.
- Локальные тесты распределения и проверка метаданных.
