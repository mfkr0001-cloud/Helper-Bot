# AI Decorator v1.0.0 — релиз

Процедурный декоратор уровней Geometry Dash 2.2081 для Geode SDK 5.11.2.

## Возможности

- **50 стилей** оформления, включая NEON, TECHNO, NATURE, GOTHIC и другие.
- **Автоматическое сканирование открытого уровня**: вручную выделять блоки или область не требуется.
- **Геометрически-ориентированная расстановка**: генератор использует измеренные прямоугольники существующих объектов и старается размещать декор вокруг структуры уровня, а не случайно по пустому прямоугольнику.
- **Настройка генерации**: стиль, плотность, палитра, акцентный режим и композиция.
- **До 520 объектов за один проход**, чтобы ограничить нагрузку на редактор.
- **Undo**: создаваемые объекты передаются редактору через обычный `createObject` с регистрацией в истории отмены.
- Генерация работает локально, без обращения к внешнему серверу.

## Установка и сборка

1. Открой репозиторий на GitHub.
2. Убедись, что в `mod.json` указаны Geode SDK `5.11.2` и Geometry Dash `2.2081`.
3. Запусти GitHub Actions вручную через **Actions → Build AI Decorator (Android) → Run workflow** либо отправь изменения в ветку.
4. Дождись успешного завершения обеих задач: **Android32** и **Android64**.
5. Скачай объединённый артефакт `AI-Decorator-Android` и установи `.geode` через Geode.

## Локальные тесты алгоритма

Требуется компилятор с поддержкой C++23:

```sh
sh tests/run-local-generator-tests.sh
```

Тест проверяет список из 50 стилей, повторяемость при одинаковом seed, безопасные координаты, отсутствие размещения внутри тестовой геометрии, поведение на длинном уровне и ограничение в 520 объектов.

## Важные ограничения релиза

- Локальные тесты проверяют алгоритм расстановки, но не заменяют проверку Android32/Android64 через Geode SDK и тестирование в Geometry Dash.
- Перед публикацией релизного `.geode` необходимо дождаться успешной сборки обеих Android-архитектур и проверить работу мода в игре.
- Предварительный визуальный просмотр декора до создания объектов и отдельная кнопка пакетного удаления/повторной генерации в этой версии не реализованы.
- Геометрия объектов оценивается по прямоугольникам, полученным от редактора; точные визуальные границы всех спрайтов не подтверждены игровым тестом.

## Состав проекта

- `src/main.cpp` — панель редактора и интеграция с Geometry Dash.
- `src/LocalGenerator.*` — планирование стиля и слоёв оформления.
- `src/DecorationPlacer.*` — геометрически-ориентированная расстановка.
- `tests/` — автономные тесты алгоритма.
- `.github/workflows/main.yml` — сборка Android32 и Android64.

Основа объединения: полный исходный проект v0.5.4 и накопительный пакет Remaster Test 10. Номер тестовой версии заменён на релизный `v1.0.0`; изменения промежуточных Test 3–9, если они отличались от переданных архивов, отдельно не подтверждены.
