# AI Decorator — Geode-мод для Geometry Dash

**Исходники:** v0.5.2  
**Целевая игра:** Geometry Dash 2.2081  
**SDK в конфигурации:** Geode 5.11.2  
**Платформы в CI:** Android 64-bit и Android 32-bit  
**Режим:** полностью локальная процедурная генерация, без AI API и интернета.

## Что мод делает сейчас

1. В редакторе уровня нажми `DECOR`, чтобы открыть плавающую панель.
2. Выдели один или несколько объектов, задающих область оформления.
3. Введи описание, например: `синий неоновый техно-город с яркими линиями`.
4. Выбери основной цвет, стиль, плотность, цветовую схему и композицию.
5. Нажми `GENERATE DECOR`.
6. Мод вычислит границы выделения и создаст декоративные объекты Geometry Dash внутри этой области.

Исходные выделенные объекты не перемещаются и не удаляются. Созданные объекты добавляются через обычный механизм редактора с включённой историей Undo.

## Что нового в v0.5.2 — подготовка Android-сборки

Добавлен GitHub Actions workflow `.github/workflows/build.yml`: он собирает Android32 и Android64 отдельно, затем объединяет результаты в один `.geode`-файл. Для запуска сборки открой вкладку Actions в репозитории GitHub и выбери workflow `Build AI Decorator (Android)`. Также генератор теперь показывает ошибку, если редактор не смог создать ни одного объекта.

## Что нового в v0.5.0 — пять основных стилей

Добавлены отдельные пресеты FUTURISM, TECHNO, NEON, GOTHIC и NATURE. Старые названия стилей сохранены для совместимости. AUTO теперь выбирает один из новых пресетов по ключевым словам описания.

## Что уже было реализовано в v0.4.0 — мод строит композицию

Предыдущая версия в основном рассыпала объекты по случайным координатам. Теперь генератор выполняет несколько проходов:

- **Каркас:** для достаточно больших областей создаёт тонкие направляющие по краям и угловые акценты.
- **Главный мотив:** добавляет характерную композицию в зависимости от выбранного типа размещения.
- **Заполнение:** размещает мелкие детали в свободных местах, проверяя дистанцию до уже поставленных объектов.
- **Палитра:** выбирает основной, акцентный и дополнительный цвета по настройкам и ключевым словам.
- **Повторяемость:** одинаковый seed, выделение и настройки дают одинаковый результат.

### Типы композиции

| Композиция | Принцип |
|---|---|
| BALANCED | Два сбалансированных кластера и рамка |
| CENTERED | Центральный знак и орбитальные акценты |
| ASYMMETRIC | Смещённый главный акцент и противовес с другой стороны |
| RHYTHM | Повторяющиеся элементы по рядам |
| MIRRORED | Парные элементы по обе стороны вертикальной оси |

### Стили

Новые пресеты: `FUTURISM`, `TECHNO`, `NEON`, `GOTHIC`, `NATURE`. Также сохранены прежние варианты: `AUTO`, `TECH`, `GLOW`, `MODERN`, `DARK`, `PIXEL`, `INDUSTRIAL`, `SPACE`, `ORGANIC`, `MINIMAL`.

### Плотность

`LOW`, `MEDIUM`, `HIGH`, `ULTRA`. Фактическое количество автоматически уменьшается для маленьких выделений; в одном проходе действует ограничение, чтобы не перегружать редактор.

## Примеры описаний

- `синий неоновый кибер-город, тонкие светящиеся линии`
- `древний храм, золотые акценты и симметричные узоры`
- `тёмная механическая фабрика с красными лампами`
- `подводные руины, бирюзовые плавные формы`
- `минималистичная белая архитектура с золотом`

Описание не отправляется в облачную нейросеть. Локальный анализатор распознаёт знакомые слова и выбирает стиль/цветовые акценты; координаты и композиция строятся алгоритмами.

## Управление плавающей панелью

| Действие | Управление |
|---|---|
| Открыть/скрыть | Кнопка `DECOR` в редакторе |
| Переместить панель | Перетащить за верхнюю полосу |
| Изменить размер | Перетащить `///` в нижнем правом углу |
| Развернуть/восстановить | `MAX` |
| Скрыть | `X` |

Положение и размер панели сохраняются между запусками.

## Структура проекта

- `src/main.cpp` — плавающая панель, получение выделения и создание объектов в редакторе.
- `src/LocalGenerator.hpp/.cpp` — разбор текста, определение темы, стиля, палитры и слоёв.
- `src/DecorationPlacer.hpp/.cpp` — построение композиции, каркас, мотивы, проверка расстояний и координаты объектов.
- `tests/LocalGeneratorSmoke.cpp` — проверки локального анализатора и генератора расстановки.
- `tests/run-local-generator-tests.sh` — запуск тестов без Geode SDK.
- `.github/workflows/build.yml` — CI-сборка и объединение Android32/Android64.
- `mod.json` — метаданные мода.

## Проверка

Локальные тесты алгоритма:

```bash
./tests/run-local-generator-tests.sh
```

Сборка Geode-мода требует установленного Geode SDK и Geode CLI:

```bash
geode build
```

Для Android используйте соответствующую платформу Geode CLI, например `android64` или `android32`.

**Важно:** в текущей среде Geode SDK и Geometry Dash не установлены, поэтому настоящая компиляция `.geode` и запуск внутри игры не подтверждены. GitHub Actions выполняет настоящую сборку после отправки проекта в репозиторий. Перед публикацией нужно собрать мод через GitHub Actions/Geode CLI и проверить визуальные границы каждого используемого ID в GD 2.2081. Алгоритм проверяет координаты центров и приблизительное расстояние между деталями; точные размеры спрайтов зависят от игровых объектов и требуют внутриигровой проверки.


## Ограничения v0.5.2

Предварительный просмотр до применения, отдельная рамка выделения с ручными маркерами, управление последней генерацией и удаление только объектов AI Decorator пока не реализованы. Габариты в планировщике оцениваются консервативно; это не заменяет проверку реальных спрайтов в игре. Генератор получает область из границ выделенных игровых объектов. Проверка размеров спрайтов внутри самой игры обязательна: алгоритм ограничивает координаты центров, но точные видимые границы объектов зависят от Geometry Dash.
