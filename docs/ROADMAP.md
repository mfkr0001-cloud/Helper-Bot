# AI Decorator — состояние релиза

## Реализовано в объединённом v1.0.0
- [x] Плавающая панель редактора с перемещением и изменением размера.
- [x] Настройки стиля, плотности, палитры, акцентного режима и композиции.
- [x] 50 доступных стилей.
- [x] Сканирование геометрии всего открытого уровня без ручного выделения.
- [x] Расстановка декора с учётом существующей геометрии.
- [x] Ограничение результата до 520 объектов на один проход.
- [x] Детерминированная генерация при одинаковом seed.
- [x] Создание объектов через API редактора и регистрация в Undo.
- [x] Автономные smoke-тесты алгоритма.

## Требует проверки в игре / CI
- [ ] Успешная сборка Android32 и Android64 в GitHub Actions.
- [ ] Проверка запуска на Geometry Dash 2.2081 с Geode SDK 5.11.2.
- [ ] Проверка визуальной расстановки на нескольких реальных уровнях.
- [ ] Проверка Undo/Redo и сохранения/повторного открытия уровня.
- [ ] Проверка поведения на очень больших уровнях на реальном устройстве.

## Не реализовано в v1.0.0
- [ ] Предварительный визуальный просмотр перед созданием.
- [ ] Отдельное управление пакетами созданного декора (удалить только последний проход / regenerate без накопления).
- [ ] Отмена долгой генерации из интерфейса.
