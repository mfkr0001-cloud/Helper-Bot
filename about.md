# AI Decorator v1.0.0

Полноуровневый процедурный декоратор для Geometry Dash 2.2081 на Geode SDK 5.11.2.

- 50 доступных стилей оформления.
- Анализ геометрии открытого уровня без ручного выделения области.
- Размещение декора с учётом существующих объектов и композиции.
- Ограничение до 520 объектов за один проход.
- Созданные объекты добавляются в стандартную историю Undo редактора.

Android32/Android64 должны быть собраны через GitHub Actions. Локальные тесты генератора не заменяют проверку мода в самой игре.
